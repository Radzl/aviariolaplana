# Aviario La Plana

Web de Aviario La Plana, criadores de psitácidas en Castellón.

**Demo:** https://radzl.github.io/aviariolaplana/

## Qué es

Una web de una sola página para presentar el criadero: quiénes son, las especies que crían, su forma de trabajar, una galería y un formulario de contacto.

## Cómo está hecha

HTML, CSS y JavaScript a mano, sin framework ni dependencias. Para una web de una página con contenido que cambia poco, un framework solo añadiría peso y mantenimiento.

- **Diseño adaptable** a móvil, tableta y escritorio.
- **Menú fijo** que cambia al hacer scroll, con menú desplegable en móvil.
- **Animaciones de entrada** de cada sección al aparecer en pantalla.
- **Formulario de contacto** con validación en el navegador.
- **SEO básico:** título, descripción y `robots.txt`.

## Estructura

```
index.html      la página
css/style.css   estilos
js/main.js      menú, animaciones y formulario
img/            fotos y logotipo
```

Para verla en local basta con abrir `index.html` en el navegador.
